# Vini Digital Lab

Uma apresentação digital de Vinicius Scherer, reunindo criação visual, tecnologia, estudos e experiência profissional.

**Acesse o site:** [vinicius-scherer-portfolio.vercel.app](https://vinicius-scherer-portfolio.vercel.app/)

## Sobre o projeto

O site apresenta uma galeria de trabalhos visuais, informações sobre minha trajetória, ferramentas, idiomas e contato. A interface se adapta a diferentes tamanhos de tela e permite ampliar as peças da galeria.

## Tecnologias

- HTML, CSS e JavaScript
- Hospedagem na Vercel
- Ícones de ferramentas: [Devicon](https://devicon.dev/) e [Simple Icons](https://simpleicons.org/)

## Executar localmente

Abra `index.html` no navegador ou execute um servidor local na pasta do projeto. Não é necessária instalação de dependências.
